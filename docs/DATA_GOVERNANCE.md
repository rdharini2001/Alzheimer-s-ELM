# Data and software terms

OASIS-2 data require agreement to the provider's use terms. Keep the raw workbook, processed data, partition manifests, and per-participant predictions in an authorized research environment. The public repository provides code and aggregate results; users can obtain the data independently from [OASIS](https://sites.wustl.edu/oasisbrains/request-access/). The manuscript PDF is available from its publisher and is not included in the public code archive. The MIT license applies only to the repository's original code and documentation.

**Acknowledgment:** Data were provided in part by OASIS-2: principal investigators D. Marcus, R. Buckner, J. Csernansky, J. Morris. OASIS-2 DOI: 10.1162/jocn.2009.21407.
