04INSIDE THE MACHINEELM / EXPLAINED

Learning in
a single step.

The extreme learning machine fixes random input-to-hidden weights, applies a nonlinear transformation and solves for output weights analytically. Experiment with the activation functions below.

ELM ACTIVATION EXPLORER

THE MODEL / 01

Hidden representation.
Analytical solution.

Randomly initialized input weights are held fixed. The hidden-layer responses form a matrix whose pseudoinverse provides output weights.

H = g(XW + b)β = H⁺T

The 60-session holdout uses 64 tanh hidden units and five selected predictors: CDR, eTIV, EDUC, MMSE and nWBV.
