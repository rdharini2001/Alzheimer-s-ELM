CHAPTER 04 / THE MATHEMATICS

Learning without
backpropagation.

An extreme learning machine fixes random input-to-hidden weights and solves for output weights in a linear least-squares step. Explore the nonlinear hidden-layer functions used in this family of models.

ACTIVATION LAB / 01
Mathematical activation curves, not fitted predictions.
THE LINEAR SOLUTION / 02

Hidden representation to output weights

Weights into the hidden layer remain fixed after initialization. The hidden matrix is transformed through a nonlinear function; the output layer is obtained analytically.

H = g(XW + b)
β = H⁺T

The session-holdout experiment uses 64 tanh hidden units and five selected predictors: CDR, eTIV, EDUC, MMSE and nWBV.
